# Data demo sintetis

Seluruh berkas dalam folder ini bersifat fiktif dan tidak mengandung data perbankan atau data nasabah.

Unggah `qa_requirements.csv`, `manifest.json`, serta `run_results.json` / `schema.yml` jika diperlukan.
Demo sengaja menghasilkan `FAIL` untuk `birth_date` (`DATE` diharapkan, sedangkan aktualnya `STRING`), `WARNING` untuk kolom tambahan `religion_code`, dan peringatan kecil pada jumlah baris.
